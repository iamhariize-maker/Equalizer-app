Get the public beta

Svan needs Android 10 or later, on arm64 or x86_64. The current public beta is 0.5.5. It is distributed as an APK through GitHub, rather than through the Play Store.

Download the beta ↗︎
  1. Open the release page and read its installation notes. Download the APK and SHA256SUMS. Check the file hash against the published checksum before installing.
  2. Keep Play Protect enabled. If Android warns or blocks the install, stop and report the exact message through the bug form.
  3. Open Svan and play some music. A fresh install starts with System effects, a flat EQ curve and 0 dB preamp.
  4. Go to Hi-Fi and check “Is it working?” for the actual player connection state.

Already using an earlier preview? Export your settings first and follow the preview migration guide. Signing differences can prevent an update over an old build. Save your settings before uninstalling anything.

Find your headphones

In Sound, search the AutoEq headphone data for your model. Use a measurement-based profile when an appropriate one is available. You can also import an AutoEq profile in Presets, or paste supported APO / AutoEq text.

A correction profile is a starting point. Fit, preference and the phone’s actual processing can change the result. It is not an individual hearing test or physical volume calibration.

Choose how you listen

System effects · start here

The recommended beta engine applies EQ to eligible Android audio sessions. In this mode, Svaresa adapts using volume, output and time of day. It has no live source analysis.

Audiophile engine · experimental

This engine captures playback when the player permits it, runs Svan’s 64-bit DSP and plays it back. It enables live source-based Svaresa analysis and selective dynamic EQ. Android asks for capture permission for each session.

Some apps block capture. Bluetooth delay or echo has been reported; use System effects if you hear it. Direct, exclusive and bit-perfect output paths can limit processing. This engine cannot provide bit-perfect or USB DAC passthrough.

Svaresa or Svaramanas?

Auto master · Svaresa handles automatic tuning within explicit limits. It can control Extended EQ, while keeping your manual curve saved.

Sound guide · Svaramanas follows the sound feel and instrument priorities you choose. Try small changes and compare the same familiar passage at similar loudness.

When a player is unreachable

Hi-Fi’s optional music-detection setup guides you through authorizing a fixed Shizuku grant for Svan’s own DUMP permission. This can help discover audio sessions; it does not remove capture blocks or guarantee player compatibility. Shizuku and wireless debugging can be stopped after the grant.

Follow the full setup guide for the live steps and troubleshooting.

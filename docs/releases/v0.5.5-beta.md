# Svan 0.5.5 — public beta

**Svan** is a system-wide equalizer for Android (Android 10 or later; arm64 and x86_64). This is an early beta
for people who want to help test it on real phones. It is not a store release.

## What it does
- **System effects (recommended):** applies your EQ to other apps' audio, Wavelet-style. Low latency.
- **Audiophile engine (experimental):** captures playback and runs a 64-bit processing chain. Needs a fresh
  screen-capture-style permission each session, and can add delay on Bluetooth.
- 0.5.5 adds peak protection, selective dynamic EQ, headphone correction fitted from AutoEq data, and a
  blind listening comparison tool.

## Please read before installing
- **Never turn off Play Protect to install.** If Android warns that the app is from an unknown source or
  unrecognised, that is expected for a beta from outside the Play Store.
- **Coming from an earlier preview?** Those used a different signing key, so Android will not update over them.
  In Presets choose **Export settings**, save the file outside Svan, uninstall the old build, install this one,
  then choose **Restore settings**. Capture permission and music-detection setup may need doing again.
- **Music detection (optional):** some players only appear after a one-time setup that grants Svan the
  `DUMP` permission through Shizuku. Once it says "enabled", stop Shizuku and turn off wireless debugging and
  Developer options. Banking and UPI apps may refuse to run while those are on.
- **Payments:** if a payment app misbehaves, use System effects only and tell us which app and what it said.

## Known limits
- Sound quality is measured in tests, not guaranteed on every phone. Real-device reports are the point of this beta.
- Bluetooth delay or echo has been reported with the Audiophile engine on one phone. Use System effects if you
  hear it, and say which route and codec you used.
- Some players do not expose their audio session, so Svan cannot process them without the optional setup above.

## Privacy
Audio is processed on the device and is not uploaded. Svan downloads headphone measurement files from GitHub
when you search tuning data. There is no advertising or analytics SDK. Full notice: `docs/PRIVACY.md`.

## Reporting a problem
Open an issue using the **Bug report** form. Include phone model, Android version, player app, output route
(speaker, wired, Bluetooth and codec), which engine, and what you heard. Screenshots help; do not post anything private.

## What it does
- Fresh installs start with System effects, Flat settings and 0 dB preamp, without a required setup wizard.
- Optional music-detection setup now has live steps, debugging guidance and retry messages. Hi-Fi shows
  the actual connection state and offers a limited local diagnostic summary and background help.
- **System effects (recommended):** applies EQ to eligible Android audio sessions. Actual response and
  latency depend on the phone/player/output path.
- **Audiophile engine (experimental):** captures playback and runs a 64-bit processing chain. Needs a fresh
  screen-capture-style permission each session, and can add delay on Bluetooth.
- 0.5.5 adds peak protection, selective dynamic EQ, headphone correction fitted from AutoEq data, and a
  blind listening comparison tool.

## Please read before installing
- **Already using the original owner-signed 0.5.5 APK?** This build uses the same recovered owner key.
  Export settings as a precaution, then try updating without uninstalling. The app version/code remain
  0.5.5/12; actual phone update and grant retention still need validation. A future Play update needs
  an increasing versionCode. Never uninstall before saving settings if an update fails.
- **Never turn off Play Protect to install.** If Android warns or blocks the APK, stop and report the
  exact message; do not dismiss a warning as expected beta behavior.
- **Coming from an earlier preview?** Those used a different signing key, so Android will not update over them.
  In Presets choose **Export settings**, save the file outside Svan, uninstall the old build, install this one,
  then choose **Restore settings**. Capture permission and music-detection setup must be done again as needed.
  Follow [Moving from preview](https://github.com/iamhariize-maker/Equalizer-app/blob/ccr-f859b567-dgrdoj/docs/MOVING_FROM_PREVIEW.md) before uninstalling.
- **Music detection (optional):** some players only appear after a one-time setup that grants Svan the
  `DUMP` permission through Shizuku, with your explicit authorization. Once enabled, Shizuku and wireless
  debugging can be stopped. This is not proof of compatibility with every player.
- **Payments:** banking/payment-app interaction is unverified. If a payment app objects, disable the optional
  bubble and stop Shizuku/wireless debugging to compare, then report its exact message without credentials
  or payment details. Switching EQ engines is not a verified fix.

## Known limits
- DSP behavior has measured tests; listener preference and device compatibility are unverified for this beta.
- Bluetooth delay or echo has been reported with the Audiophile engine on one phone. Use System effects if you
  hear it, and say which route and codec you used.
- Some players do not expose usable sessions; capture-blocked sources and exclusive/direct/bit-perfect
  output paths can limit processing. Enhanced detection does not remove those platform restrictions.
- Audiophile startup can stop safely when multiple or recently recreated sessions share one app UID.
  This routing limitation was observed in CI and is not fixed by the onboarding work. Use System
  effects if capture stops; recreated/multi-session behavior still needs phone validation.

## Privacy
Audio is processed on the device and is not uploaded. Svan downloads headphone measurement files from GitHub
when you request tuning data; GitHub receives ordinary network metadata including your IP address and
requested file paths. There is no advertising or analytics SDK in the reviewed dependencies.
Full notice: [Privacy](https://github.com/iamhariize-maker/Equalizer-app/blob/ccr-f859b567-dgrdoj/docs/PRIVACY.md).

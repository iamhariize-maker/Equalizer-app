Svan is a system-wide equalizer for Android 10 or later (arm64 and x86_64).
This is an early GitHub beta for testing on real phones.

## What changed

- Backing vocals and Binaural controls shape existing stereo side energy in the Audiophile engine.
  They cannot isolate stems. Measured tests check the response and preserve the mono sum.
- Playback continuity changes add a 40 ms primed output cushion, a 250 ms capture buffer,
  adaptive output buffering and system-effect volume re-arming after restart. These changes
  address tested failure cases; the owner's original phone crackle has not been reproduced.
- Whole-phone EQ can process the output mix when a playing app hides its session and no player
  is routed. Availability depends on the phone and output path.
- Enhanced detection has a direct Shizuku route when the helper process cannot provide reports.
  The user-tapped “Keep enhanced detection without Shizuku” control grants only Svan's own DUMP
  permission, allowing Shizuku to be uninstalled. Android can revoke the grant; reinstalling Svan
  requires setup again.
- Notification-listener player recognition was removed after Play Protect flagged the preview.
  The compiled capability policy forbids notification listeners, SMS and accessibility services.

## Phone evidence

The owner reports working playback on their TECNO LH7n preview. Their photo shows Spotify routed

## Before installing

- Export settings and save them outside Svan before updating.
- An original owner-signed 0.5.5 installation should update in place: this beta uses the same
  signing identity and increases versionCode from 12 to 13. Phone update and grant retention
  have not yet been verified.
- Preview installations use a different signer. Export settings, uninstall the preview,
  install this beta, then restore settings. Repeat detection and capture setup as needed.
- Never turn off Play Protect to install. If Android warns or blocks the APK, stop and report
  the exact message.
- System effects is the recommended starting engine. Audiophile capture needs a fresh
  capture permission per session and can add delay. Use System effects if Bluetooth echoes
  or delays. Exclusive/direct/bit-perfect player paths can bypass processing.
